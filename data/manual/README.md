# Manual data

Figures copied by hand from reports that publish no machine-readable data.
Every row carries `source_key` (a `paper/references.bib` key) and `page`.

**Page convention:** `page` is the PDF page index (what a PDF viewer shows),
because printed folios are missing or inconsistent across reports. Where the
printed folio differs, `notes` gives it.

| File | Source | Checked |
|---|---|---|
| `irena_offgrid_people.csv` | IRENA, *Off-grid Renewable Energy Statistics 2025*, tables on PDF pp. 57, 59, 61 (printed pp. 51, 53, 55) | Every value re-read from the PDF text layer, 2026-10-30 |
| `report_headlines.csv` | Tracking SDG7 2026; GOGLA 2026; GSMA State of the Industry 2026 | Each phrase located on the stated PDF page, 2026-10-30 |
